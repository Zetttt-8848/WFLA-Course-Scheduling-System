# WFLA Course Scheduling System

本机运行的中文排课网站，MIT 开源。当前版本 **v0.2.0**，重点是选课、资源约束和可审计的课表，页面使用 Flask/Jinja2。

## 下载与启动

[下载源码 ZIP](https://github.com/Zetttt-8848/WFLA-Course-Scheduling-System/archive/refs/heads/main.zip)，解压后双击 `start.bat`。需先安装 Python 3.11—3.13 并加入 PATH；首次启动下载依赖，后续排课不调用外部 API。浏览器地址为 **http://127.0.0.1:5000**，无需域名或 Excel 软件。数据库和真实输入仅保存在本机 `instance/`，不包含在下载包中。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -X utf8 -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 run.py --open
```

macOS/Linux 使用 `.venv/bin/python`，尚未在这些平台实测。端口占用时可用 `--port 5001`。

## 老师怎么用

1. 首页点 **新建学期**，在“规则”确认年级节次、学科课时和自修要求。
2. **录入选课**：下载“一行一名学生”或“一行一个组合”的 Excel 模板后上传，也可在网页选择六门课并填写行政班、人数。组合模式生成匿名学号；补齐姓名/学号后才能对应真实个人。
3. **配置资源**：按学科、HL/SL、任教年级填写教师人数，或提供姓名。跨层级、跨年级同一老师只算一个资源，跨科资格在高级数据表增加，不能重复登记成两人。
4. **公共课分工**：TOK、Career Navigation 按两个行政班一位老师建立分工，两个班分别上课。六个行政班默认需要三位不同老师。
5. **教室**：确认实际容量，补上真实实验室及备用C楼教室房号；默认配置不虚构实验室。
6. **检查并生成**：校验失败会给出定位；成功方案经过独立检查，可切换学生、教师、教室、教学班课表，并导出 Excel/CSV、打印或手动移动学科课次。

首轮配置完成后，可在当前学期继续导入选课。导入会追加学生，重复学号拒绝整次导入；完整模板恢复则另建输入版本。所有编辑保存新版本，不覆盖旧课表。历史版本在“数据 → 备份与版本”。

只有“Physics HL 共多少人”这样的各科边际人数无法恢复学生的六科组合。本系统需要组合人数或逐人选课，不能据边际人数编造学生组合。只有教师人数时会建立明确标注的教师名额；老师有不同禁排或资格时应补充具体身份。

## 当前学校规则

以下为需求方提供的校内规则，不是声称所有 IB 学校均如此。更正后的默认模式为 **每生六门选课、具体课次灵活并行**。旧的严格六区块模式保留兼容，不与新模式混用。

| 项目 | 11年级 | 12年级 |
|---|---|---|
| 周一至周四 | 每天9节，上午4/下午5 | 每天8节，上午4/下午4 |
| 周五 | 8节，上午4/下午4 | 7节，上午4/下午3 |
| 周总节数 | 44 | 39 |
| English B HL/SL | 各5节 | 各6节 |
| Chinese A、MAA、Physics、Chemistry、Biology、Economics、History HL/SL | 各5节 | 各5节 |
| TOK | 4节 | 3节 |
| 体育、会考地理、会考历史、会考政治、Career Navigation | 各1节 | 不安排 |
| 每生自修 | 5节 | 4节 |
| 待安排 | 0 | 暂留1节，仍需确认用途 |

网页只显示星期和节次，不标钟点；第4节后不可连堂。不同年级同一编号节次暂按同步处理。12年级典型选课合计31节，另加TOK3、自修4，为38节，剩余1节不自动冒充自修。其他选课路径必须配置其实际课时，并通过逐人周总量校验。

G11/G12 默认3 HL＋3 SL，4 HL＋2 SL须按学期记录有效批准。G10 仍用 NONE、不允许 English A；G10 新的每日节数和自修课时尚未提供，可在高级数据表配置，不能推断与11年级完全一致。新学期课程初值只含本轮明确课时的学科，English A、小语种、艺术等可在课程表添加。

## 教室与自修

- A3—5楼24间教室优先；A2楼8间为较低优先级。每层只建立01、03、04、06、07、08、09、10，02/05办公室禁止加入。A1楼房号尚未提供，不自行猜测。
- 普通教室暂按22座初始化；C201/C202按44座，C301/C302按22座。容量是“每行政班约22人”的换算初值，使用前应核实实际座位。
- G11/G12 自修仅用C301/C302，两个年级统一占用座位，不能各自重复计算容量。G10自修应配置C201/C202。
- 体育使用操场，默认同时容纳一个约22人的行政班；若可分区并行，应按实际场地另行登记。
- C楼普通备用教室的房号和实验室均需补充，不把自修室自动当普通课堂。普通教室不能自动当实验室。
- 理科默认2节实验（含1次双节）只是可修改的初值，包含在总5节内。实验室的真实房号、类型、容量尚待提供。

## 求解与结果含义

`flex_solver.py` 用统一 CP-SAT 联合安排分班、教师、教室、学科课次、公共课和自修。硬约束包括逐人不重叠、年级关闭节次、师资资格/禁排/周负荷、教室类型/容量、规定课时、连续实验课及自修座位。

自修是求解变量，占用真实的房间座位；未安排的空堂只显示“待安排”。公共课可与其他班学科课并行，但共享师生和房间统一检查。对六科分班及公共课完全相同的已预分班学生，模型仅合并冗余的共同可用时间约束，仍分别求解每人的自修座位，允许分流到不同房间。

优化按有界权重依次考虑：较少教学班、较低教室使用代价、学科课在各天的集中超额。有限时限下 `FEASIBLE` 仅为有效方案，**不表示最佳**；`OPTIMAL` 也只表示当前候选班数和这三个目标下已证明最优。其他教学偏好、完整六项软评分仍未实现。显式测试用的 `quick_feasible` 可提前返回首个解；网页新学期和网页演示默认在60秒预算内继续优化。

`max_sections=0` 暂用容量下限＋1个候选班的有限范围，校方可调大。`INFEASIBLE` 仅针对该范围；`UNKNOWN` 是未得出结论，不能写成无解。当前中文诊断是资源核查方向，尚非经重算证明的最小松弛方案。

## 演示与测试

首页展开“体验演示”可载入新规则的12人小样例；名单、教师、实验室完全虚构，含预设分班，具体课次/教师/房间由求解器计算。旧v0.1演示的规模性能不能用来代表新增公共课和座位约束后的性能。实测范围见[验收记录](docs/验收记录.md)。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -X utf8 -m pytest -q --basetemp=instance/pytest-run
```

`--basetemp`只指向专用测试目录，pytest会清理它；勿指向存放学校数据的目录。`pytest.ini`将测试发现范围限定在tests，避免收集下载包解压后的重复测试。

## 独立命令行

网页“数据 → 备份与版本”导出的完整输入可直接交给CLI：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m wfla validate input.xlsx
.\.venv\Scripts\python.exe -X utf8 -m wfla solve input.xlsx result.json --seconds 120
.\.venv\Scripts\python.exe -X utf8 -m wfla audit input.xlsx result.json
.\.venv\Scripts\python.exe -X utf8 -m wfla export input.xlsx result.json schedule.xlsx
```

`python -m wfla demo demo.xlsx --per-grade 12`仍生成旧六区块演示，供兼容回归；新规则演示可从网页载入再导出完整输入。模板、JSON、结果均使用共用数据契约。

## 模块与边界

`schema`/`storage`：表契约与SQLite版本快照；`validation`/`school_validation`：规则与周总量；`intake`/`io`：简化录入、模板与导出；`solver`：旧六区块兼容；`flex_solver`：新模式；`audit`：独立重算；`web`/`templates`：中文页面。
