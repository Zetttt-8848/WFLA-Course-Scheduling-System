# v0.2：年级规则、灵活并行与简化录入

用户本轮明确允许将“严格六区块”改为“每人仍选六门，课次灵活并行”，并确认TOK/Career一位老师分别教两个行政班。新增模式不会修改旧版本输入；旧结果仍可查看、审计和导出。

## 新数据与模型

- `calendar`：grade/day/periods，统一9节索引，但不同年级不同日期只允许自身开放节次。
- `activities`：id/name/grade/admin_classes/periods/teacher/room_type/room。按班分别建组，或以activity_members明确成员，不挤占六门学科选课。
- `study_rules`：grade/periods/rooms/unassigned。自修按学生选择房间和节次，同房同节所有年级合计不能超过座位数。
- `rooms.preference`：非负使用代价，A3—5优先，A2较低，实际备用房可设置更高代价。
- 新输入、旧输入、课堂公共课和自修都由独立审计检查；周预算不平衡在排课前拦截。

灵活模式不再对所有班施加学科块时段相等或每生区块AllDifferent；逐学生资源不重叠是直接硬约束。允许Biology与不同层级Chemistry的若干课次交错，但不会仅凭叙述强制所有学生具有同样的课次结构。

统计录入必须是六科联合组合人数，不能是各科总人数。匿名学生对应组合与行政班；逐人模板含学号、姓名、年级、行政班、六门课程编码。教师名额允许开始规划，但同一老师不能在两组重复计算。

## 已确认的量与剩余信息

11年级44节：典型六科学科30、TOK4、五项公共课各1、自修5。12年级39节：典型六科31、TOK3、自修4，另1节待确认；用户后续答复重申11年级自修5，并未确认12年级额外1节的用途。

A房间与C自修室按约22人/行政班换算容量。实际座位数、实验室房号/能力、C楼普通备用房、G10每日节次和自修课时尚待录入。理科实验2节是初值，不是已获校方确认的配额。小语种、艺术、English A的当前课时亦需补充。

## 页面

首页只保留“录入选课 / 配置资源 / 检查并生成”；详细技术表、备份、旧版本、演示入口折叠。个人课表只呈现学科、层级、教室、教师与节次；下午从第5节开始，关闭节次用横线表示，不显示钟点。

## 优化的范围

词典序目标：教学班数、房间代价、学科每日集中超额。任何未证明最优的结果只报告可行。自修不是用空白格事后伪造，TOK/Career也不是混在六科中的额外选课。完整软评分、最小松弛和全规模性能继续列为未完成，不能沿用v0.1的简单样例速度宣称新模型达标。
